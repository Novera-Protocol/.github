# Support

## Current public scope

Novera Protocol is in a foundation and prototype-design stage. Public GitHub materials describe product direction, architecture boundaries, and governance posture. They do not provide a production application, token, stablecoin, payment rail, custody service, identity-verification service, or legal-document workflow.

## Getting help

- Review the public organization profile and the documentation in the relevant repository before requesting clarification.
- Use repository documentation for public product and architecture context.
- Follow `SECURITY.md` for a security-sensitive matter; do not post potential vulnerabilities publicly.

## Support availability

There is no public service desk, SLA, account-support channel, or customer-success program at this stage. Official support and engagement channels will be published before any customer-facing production offering is launched.

## Boundaries

Do not submit personal data, identity documents, asset records, payment information, legal documents, credentials, private keys, or confidential business information through public GitHub channels.
