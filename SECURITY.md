# Security Policy

## Scope

Novera Protocol's public GitHub organization currently hosts public product, governance, and community materials. The private platform, wallets, smart contracts, custody, payment, identity-verification, legal-document, and live blockchain integrations are not publicly operated or represented here.

## Reporting a vulnerability

Do **not** disclose suspected security vulnerabilities in a public Issue, Discussion, pull request, or social post.

Where GitHub presents a private vulnerability-reporting option on the affected repository, use that channel and provide a concise description, affected file or feature, reproduction steps, and potential impact. Do not include credentials, private keys, personal data, customer data, or exploit payloads.

If private reporting is unavailable, do not publish technical details. A designated confidential reporting channel will be added before any production service or public codebase is released.

## Response expectations

Novera will acknowledge reports and assess remediation priority when a maintained public repository or future released service is in scope. No service-level agreement, bounty program, or production security assurance is currently offered.

## Safe-harbor boundary

Do not access accounts, systems, data, or infrastructure without explicit authorization. Testing against public documentation repositories must not attempt to obtain secrets, bypass access controls, or disrupt services.
