# Contributing to Novera Protocol

## Purpose

Novera Protocol uses public GitHub repositories to communicate selected product, architecture, governance, and ecosystem materials. Repository-specific contribution guidance takes precedence over this organization-wide default.

## Before contributing

- Read the repository README, public disclosures, `SECURITY.md`, `SUPPORT.md`, and `CODE_OF_CONDUCT.md`.
- Keep all statements accurate, sourceable where appropriate, and consistent with Novera's pre-launch status.
- Do not include credentials, private keys, customer information, identity documents, asset data, payment information, legal documents, or confidential business information.
- Do not submit token, stablecoin, wallet, custody, payment, KYC/KYB, smart-contract, or production-infrastructure material unless a repository explicitly requests it.

## Changes and review

Public material is curated for accuracy, security, legal and regulatory awareness, and brand integrity. Maintainers may decline, edit, or defer contributions that introduce unsupported claims, security exposure, personal data, or inappropriate scope.

## Security-sensitive matters

Do not use public issues or pull requests to report vulnerabilities. Follow `SECURITY.md` instead.
